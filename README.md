## 01. Доходы и инвестиции в жилища по регионам

**Задача:** оценить зависимость инвестиций в жилищное строительство
от среднедушевых доходов населения по регионам; построить модель,
спрогнозировать показатель для Республики Карелия (2012) и
интерпретировать эластичность.

**Данные:** панель по регионам (доходы, инвестиции, регион, год).

**Что сделано:**
- Обработка данных: приведение числовых признаков к `numeric`
  (замена запятой на точку), удаление строк с нулями (отсутствие данных).
- Удаление выбросов по квантилям (10–95%) для доходов и инвестиций.
- Визуализация: диаграмма рассеяния + линия регрессии.
- Оценка коэффициента корреляции Пирсона и проверка значимости
  (`cor.test`).
- Линейная модель `outcome ~ income`; оценка MAPE.
- Логарифмическая модель `log(outcome) ~ log(income)`; сравнение MAPE
  с линейной.
- Отдельная модель для Республики Карелия; прогноз на 2012 год
  с 95% доверительным интервалом.
- Интерпретация коэффициентов и эластичности.

**Результаты:**

| Модель | Метрика | Значение |
|--------|---------|----------|
| Корреляция | r | 0.394 (p < 0.05, значима) |
| Линейная `outcome ~ income` | R² | 0.155 |
| Линейная | MAPE | 265% |
| Лог-модель `log~log` | MAPE | 138% |
| Лог-модель | β (эластичность) | 0.9708 |
| Прогноз Карелия 2012 | отклонение от факта | 306.61% |

**Выводы:**
- Связь доходов и инвестиций **положительная, но слабая** (r = 0.394):
  доходы влияют, но не являются ключевым фактором.
- Линейная модель объясняет лишь ~15% разброса (R² = 0.155) и даёт
  очень высокую ошибку (MAPE 265%) - без логарифмов модель слишком грубая.
- Лог-модель адекватнее (MAPE 138%), но ошибка всё ещё высока для
  межрегиональной модели.
- **Эластичность β = 0.9708 < 1** - инвестиции **неэластичны по доходу**:
  при росте доходов на 1% инвестиции растут примерно на 0.97%;
  для роста инвестиций на 1% доход должен вырасти ~на 1.03%.
- Модель по всем регионам плохо описывает отдельный регион (Карелия:
  переоценка на ~307%) - инвестиции зависят от дополнительных факторов,
  не учтённых в модели.

**Файл:** `Induvidual1/Induvidual1script.R`

## 02. Множественная регрессия: фиктивные переменные и мультиколлинеарность

**Задача:** оценить влияние доходов, населения, расстояния до Москвы,
широты и федерального округа на инвестиции в жилища; проверить
мультиколлинеарность, оценить стандартизованные коэффициенты
и эластичности, построить прогноз для Республики Карелия.

**Данные:** панель по регионам (доходы, инвестиции, население,
расстояние до Москвы, широта, федеральный округ, год).

**Что сделано:**
- Корреляционная матрица числовых признаков + проверка значимости
  корреляций (p-value) через `cor.test`, визуализация `corrplot`.
- Фиктивные переменные для федеральных округов (`as.factor`).
- Множественная линейная регрессия:
  `outcome ~ income * federal_district + population + distance_to_moscow + latitude`.
- Стандартизованные коэффициенты (`lm.beta`).
- Проверка мультиколлинеарности через VIF (`car::vif`).
- Проверка значимости модели в целом (F-статистика).
- Лог-лог модель для оценки эластичностей:
  `log(outcome) ~ log(income) * federal_district + log(population) + ...`.
- Расчёт прямых эластичностей (log-переменные) и косвенных
  (через средние) для остальных признаков.
- Прогноз для Карелии (2012) с 95% доверительным интервалом;
  оценка ошибки прогноза.
- Исследование неоднородности: остатки модели, boxplot выбросов.

**Результаты:**

| Модель / показатель | Значение |
|---------------------|----------|
| R² (множественная регрессия) | ≈ 0.67 |
| Adjusted R² | ≈ 0.62 |
| Стандартизованный коэф. population | 0.73 (p < 0.001) |
| VIF distance_to_moscow | ~27 |
| VIF federal_district | ~136 |
| Эластичность по income (лог-лог) | 1.34 |
| Эластичность по population (лог-лог) | 0.87 |
| Эластичность по distance_to_moscow | ~ −3.6e-5 |
| Эластичность по latitude | ~ −1.86e-4 |

**Выводы:**
- **Население - ключевой фактор**: статистически значимо (p < 0.001),
  наибольший стандартизованный коэффициент (0.73). Рост населения
  напрямую повышает инвестиции.
- **Доходы** в множественной регрессии слабо значимы (p ≈ 0.09),
  но в лог-лог модели дают **эластичность 1.34**: рост доходов на 1%
  увеличивает инвестиции на ~1.34% (эластично).
- **Эластичность по населению 0.87** — рост на 1% даёт ~0.87%
  инвестиций (неэластично, но значимо).
- **География влияет слабо**: расстояние до Москвы и широта
  практически не влияют (эластичности ~10⁻⁴–10⁻⁵).
- **Мультиколлинеарность**: VIF высокий для `distance_to_moscow` (~27)
  и набора `federal_district` (~136) — оценки отдельных коэффициентов
  могут искажаться, но модель остаётся интерпретируемой для главных
  факторов (population, income).
- Модель объясняет ~62–67% вариации инвестиций; часть влияния
  остаётся необъяснённой — есть неучтённые факторы.

**Файл:** `Induvidual2/Induvidual2script.R`


## 03. Временной ряд: строительство жилья, ARIMA

**Задача:** проанализировать месячный временной ряд строительства жилья
для одной семьи (с 1976 г.), определить структуру (тренд, сезонность),
подобрать ARIMA-модель, проверить адекватность и построить прогноз.

**Данные:** месячный ряд `Value` с 1976 г., `frequency = 12`.

**Что сделано:**
- Приведение числовых значений к `numeric` (замена запятой на точку).
- Построение объекта `ts` с месячной частотой.
- Визуализация ряда (`autoplot`) — оценка тренда и сезонности.
- Анализ ACF (зависимость от прошлых значений) и PACF
  (порядок AR-компоненты).
- Автоматический подбор ARIMA через `auto.arima`.
- Диагностика остатков (`checkresiduals`): автокорреляция, нормальность,
  Ljung-Box.
- Прогноз на 3 месяца с визуализацией.

**Результаты:**

| Показатель | Значение |
|------------|----------|
| Модель (auto.arima) | **ARIMA(1,1,0)(0,1,1)[12]** |
| Коэффициенты | ar1 = −0.2916; sma1 = −0.8810 |
| AIC / AICc / BIC | 760.68 / 760.90 / 768.83 |
| RMSE (train) | 6.16 |
| MAPE (train) | 6.39% |
| Ljung-Box p-value | **0.317** (df = 22) |
| Прогноз на 1 мес. (Jun 1986) | **86.14** (95% ДИ: 73.13–99.14) |
| Прогноз на 2 мес. (Jul 1986) | **81.09** (95% ДИ: 65.16–97.03) |
| Прогноз на 3 мес. (Aug 1986) | **79.04** (95% ДИ: 60.06–98.03) |

**Выводы:**
- В ряду выражены **тренд и сезонность** (месячная периодичность) —
  видно по графику и ACF (медленное затухание, сезонные пики).
- `auto.arima` подобрал **ARIMA(1,1,0)(0,1,1)[12]**:
  - `d = 1` — тренд устранён взятием первой разности;
  - `(0,1,1)[12]` — сезонная составляющая: сезонная разность
    и сезонное MA-слагаемое (sma1 = −0.8810);
  - `ar1 = −0.2916` — слабая отрицательная зависимость от прошлого месяца.
- **Диагностика остатков:** Ljung-Box p = 0.317 > 0.05 → нет оснований
  отвергать H₀; остатки — случайный шум, автокорреляции нет.
  **Модель адекватна.**
- Качество на обучающей выборке: MAPE = 6.39%, RMSE = 6.16 —
  ошибка прогноза умеренная.
- **Прогноз на 3 месяца:** 86.14 -> 81.09 -> 79.04 (убывающий тренд).
  Доверительный интервал расширяется с горизонтом (73–99 → 60–98) —
  типично для ARIMA.
- Сезонность **учтена** (сезонная компонента `[12]`), поэтому отдельная
  SARIMA не требуется.

**Файл:** `Induvidual3/Induvidualscript.R`
